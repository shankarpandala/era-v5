01

How many strategies? Eight.

Session 4 §14 names them as “the standing definition of what turns collected data into training data”: normalization, format discipline, quality filtering, deduplication, language validation, PII removal, decontamination, and the manifest. Counted carefully so the total is not inflated: extraction lives in Session 3 (not rebuilt here); deduplication spans two lesson sections (§6 mechanism + §7 at scale) but is one strategy; the lesson’s 10 interactive widgets are a UI count, not a strategy count. One ordering rule sits under all eight: cleaning happens before the content hash is computed, so every ID reflects cleaned text.

02

What dataset was picked — and from where

Decoding the assignment’s example

The linked example — Qwen3.6-35B-A3B-Claude-4.7-Opus-Reasoning-Distilled — is a model, not a dataset: a Qwen3.6 MoE fine-tuned on ≈7,800 conversations distilled from Claude Opus 4.7 with <think> reasoning traces. So “a 10–100M dataset like this” means a reasoning-distillation conversation dataset in the 10–100M-token band — the kind of data that trained that model. (Its own raw dataset, reasoning-distill-claude-opus-4-7-max, is only ≈8M tokens — below the band.)

Main pick · Bespoke-Stratos-17k

16,710 conversations distilled from DeepSeek-R1 (same genre as the example’s Claude-Opus distill): 10k math (NuminaMATH: AIME, MATH, Olympiads), 5k coding (APPs + TACO), 1k science & puzzles (STILL-2). Apache-2.0. Measured here: M Qwen-2.5 tokens — inside 10–100M.

Why it’s perfect for this assignment: it arrives dirty in exactly the ways Session 4 teaches — literal <|begin_of_thought|> ghost tags in every assistant turn, cross-source near-duplicate problems, real overlap with math benchmarks, and a conversation format that needs unifying.

Sovereign companion · Sangraha verified/tel

The Session 3 sovereign corpus: 251B tokens over 22 Indic languages, with the honest “verified human-origin” split (Telugu: 16.3B headline → 3.7B verified). We take a deterministic slice — the first verified Telugu docs (M tokens) — and run the same 8 stages, because an India-first pipeline must be proven on Indic text, not asserted on English. The sourcing shelf — where corpora come from, seen from India

Every serious corpus starts at a handful of public resources. Common Crawl is the headwater — a nonprofit crawl of the public web since 2008, petabytes per monthly snapshot — and nearly every English pretraining set below is a filtered view of it. The India-first lesson from Session 3: the same headwater yields slivers for Indic languages (CulturaX holds 2,847B English tokens beside a few B per Indic language), so sovereign corpora need native collection, not just better filtering.

The India-first proof — measured, not asserted

The sovereign thread runs to the character level. These are the five places the pipeline had to be script-aware, each with the number that proves it on real Telugu text.

Tokenizer fertility — Session 3’s warning, measured here

The same Qwen-2.5 tokenizer that spends characters per token on English spends only chars/token on Telugu — so a fixed token budget buys far fewer Telugu sentences. Tokenizer design and corpus design are one system; this is why Assignment 3 sized an Indic-aware 262K vocabulary.

08

Pipeline v1.1 fixes · residual concerns

Three score-critical precision bugs from the v1.0 review are fixed in clean.py (pipeline 1.1.0). Remaining items are scope honesty, not defects.

FIXED · PII

Version-like dotted quads no longer over-masked

v1.0 examples such as 7.2.1.3 / bare 1.1.1.1 were masked as [IP]. v1.1 exempts version-like quads (attached v / version keywords, low-octet quads without network context) and RFC 5737 TEST-NET ranges. Real ping 1.1.1.1 / server 8.8.8.8 contexts still mask.
FIXED · DECONTAM

Template false positives reduced

v1.0 rare-13-gram hits sometimes matched shared problem templates (factorial reminders, plane phrasing) across different items. v1.1 excludes multi-item template grams, tightens DF cap (10→5), requires ≥3 rare grams at ≥35% containment, and confirms with full-item word Jaccard ≥0.22. Template rejects are counted in the stats.
FIXED · QUALITY

Domain-aware heuristics for math/code

English stop-word / mean-length / symbol-ratio rules no longer hard-drop math or code docs (the “Martians measure angles in clerts” trap). Soft-rule would-fires are still measured and reported. Structural rules (empty, lorem, extreme length, non-printable, heavy line dupes) still apply. FineWeb-Edu gate remains 1.5 after the measured LaTeX-density bias.
SCOPE

Telugu decontam is honest zero, not complete

0 hits vs English math benchmarks is expected for Telugu web text — and stated as such. A full Indic pool needs MILU / IndicQA / translated-benchmark fingerprints in the same scan. The Telugu slice is a deterministic first-N of verified/tel — enough to prove every India-first rule without claiming full-corpus cleaning.
NEAR-DUP UNIT

0 full-doc near-dups is a dataset fact, not a failure

MinHash found 0 doc-level near-dup clusters; the real duplication lived at the prompt level (same-problem, different-trace collapses at J≥0.9). Reporting both is the lesson: choose the right unit of dedup for the genre.
REPRODUCE COST

Classifier labeling is the long pole

Stages 1–2 + 4–8 are minutes on CPU; FineWeb-Edu scoring is ~1–2 h and is cached by content hash so re-runs stay deterministic. Pipeline version 1.1.0; seed 42; --verify proves bit-identical content hashes.
