01

How many strategies? Eight.

Session 4 §14 names them as “the standing definition of what turns collected data into training data”: normalization, format discipline, quality filtering, deduplication, language validation, PII removal, decontamination, and the manifest. Counted honestly: the pipeline overview (§2) also lists extraction, which Session 3 already built — so it’s 9 pipeline stages of which 8 are built in this session. (Deduplication spans two sections — mechanism §6 and at-scale §7 — but is one strategy; and the lesson’s 10 interactive widgets are a different count than its 8 strategies.) One rule sits under all of them: cleaning happens before the content hash is computed, so every ID reflects cleaned text.

02

What dataset was picked — and from where

Decoding the assignment’s example

The linked example — Qwen3.6-35B-A3B-Claude-4.7-Opus-Reasoning-Distilled — is a model, not a dataset: a Qwen3.6 MoE fine-tuned on ≈7,800 conversations distilled from Claude Opus 4.7 with <think> reasoning traces. So “a 10–100M dataset like this” means a reasoning-distillation conversation dataset in the 10–100M-token band — the kind of data that trained that model. (Its own raw dataset, reasoning-distill-claude-opus-4-7-max, is only ≈8M tokens — below the band.)

Main pick · Bespoke-Stratos-17k

16,710 conversations distilled from DeepSeek-R1 (same genre as the example’s Claude-Opus distill): 10k math (NuminaMATH: AIME, MATH, Olympiads), 5k coding (APPs + TACO), 1k science & puzzles (STILL-2). Apache-2.0. Measured here: M Qwen-2.5 tokens — inside 10–100M.

Why it’s perfect for this assignment: it arrives dirty in exactly the ways Session 4 teaches — literal <|begin_of_thought|> ghost tags in every assistant turn, cross-source near-duplicate problems, real overlap with math benchmarks, and a conversation format that needs unifying.

Sovereign companion · Sangraha verified/tel

The Session 3 sovereign corpus: 251B tokens over 22 Indic languages, with the honest “verified human-origin” split (Telugu: 16.3B headline → 3.7B verified). We take a deterministic slice — the first verified Telugu docs (M tokens) — and run the same 8 stages, because an India-first pipeline must be proven on Indic text, not asserted on English. CC-BY-4.0.

The sourcing shelf — where corpora come from, seen from India

Every serious corpus starts at a handful of public resources. Common Crawl is the headwater — a nonprofit crawl of the public web since 2008, petabytes per monthly snapshot — and nearly every English pretraining set below is a filtered view of it. The India-first lesson from Session 3: the same headwater yields slivers for Indic languages (CulturaX holds 2,847B English tokens beside a few B per Indic language), so sovereign corpora need native collection, not just better filtering.

The India-first proof — measured, not asserted

The sovereign thread runs to the character level. These are the five places the pipeline had to be script-aware, each with the number that proves it on real Telugu text.

Tokenizer fertility — Session 3’s warning, measured here

The same Qwen-2.5 tokenizer that spends characters per token on English spends only chars/token on Telugu — so a fixed token budget buys far fewer Telugu sentences. Tokenizer design and corpus design are one system; this is why Assignment 3 sized an Indic-aware 262K vocabulary.
