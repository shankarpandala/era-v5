Kronecker Embedding V2: embeddings that carry mathematical structure

A deterministic, non-learned token embedding whose dims split into a character block (orthographic identity, invertible) and a numeric block where vector addition IS integer addition on the linear value dim (bit-exact in float32) and multiplication becomes addition on the log dim. A 2-layer CPU-trained transformer using it beats learned embeddings in-range and generalizes to number tokens never seen in training.
